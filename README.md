# Human Speak فارسی

مهارتی برای ویرایش، بررسی و نوشتن متن فارسی با صدای خود نویسنده. کلیشه‌هایی مثل «در دنیای پرشتاب امروز»، «نقش کلیدی ایفا می‌کند» و «این فقط یک ابزار نیست، بلکه یک تحول است» را در بافت متن پیدا می‌کند؛ بعد، به‌جای جایگزینی مکانیکی واژه‌ها، جمله را روشن‌تر می‌نویسد. متن خوب را بی‌دلیل دستکاری نمی‌کند.

این ابزار **تشخیص‌دهندهٔ متن هوش مصنوعی نیست** و دربارهٔ اینکه متن را چه کسی نوشته قضاوت نمی‌کند. برای کپشن، پست، متن وب، پیام کاری و نوشته‌های فارسیِ رسمی یا محاوره‌ای قابل استفاده است؛ نتیجه همچنان نیاز به بازبینی نویسنده دارد.

سازنده و بومی‌ساز نسخهٔ فارسی: [عرفان ایرانشاد](https://erfaniranshad.ir) · نسخهٔ **1.0.0**

## نصب

پیش‌نیاز روش اول: Node.js و `npx`.

```sh
npx skills add amirerfaniranshad-alt/human-speak --skill human-speak --global --yes
```

یا در Claude Code از نصب پلاگین استفاده کنید:

```text
/plugin marketplace add amirerfaniranshad-alt/human-speak
/plugin install human-speak@human-speak
```

در روش پلاگین Claude Code نام مهارت `/human-speak:human-speak` است؛ نصب مستقل، نام کوتاه `/human-speak` را در محیط‌هایی که از آن پشتیبانی می‌کنند در دسترس می‌گذارد. در Codex، مهارت را با `$human-speak` فراخوانی کنید.

می‌توانید از دستیار خودتان هم بخواهید: «مهارت human-speak را از https://github.com/amirerfaniranshad-alt/human-speak نصب کن.» نصب یک نسخهٔ محلی را با تغییرات آیندهٔ GitHub خودکار به‌روزرسانی نمی‌کند؛ برای نسخهٔ جدید دوباره نصب کنید.

## استفاده

### ویرایش متن

```text
/human-speak

این متن کپشن من است. محاوره‌ای بماند و فقط جاهایی را تغییر بده که کلیشه‌ای شده:
[متن]
```

خروجی پیش‌فرض، متن کامل ویرایش‌شده و توضیح کوتاه تغییرات است. برای خروجی بدون توضیح بنویسید «فقط متن نهایی».

### بررسی بدون بازنویسی

```text
/human-speak این متن را از نظر کلیشه‌های نثر هوش مصنوعی بررسی کن، بازنویسی نکن:
[متن]
```

برای هر مورد، عبارت شاهد، نام الگو و راه اصلاح می‌گیرید؛ نه نمره یا ادعای تشخیص نویسنده.

**نمونهٔ ویرایش:**

> قبل: «در دنیای پرشتاب امروز، ما هر روز سفارش‌ها رو دستی توی دو فایل ثبت می‌کنیم و این موضوع اهمیت ویژه‌ای داره.»
>
> بعد: «هر روز سفارش‌ها رو دستی توی دو فایل ثبت می‌کنیم.»

جزئیات واقعی و لحن محاوره‌ای مانده‌اند؛ مقدمه و جملهٔ بی‌اطلاعات حذف شده‌اند. این فقط نمونه‌ای از یک متن فرضی است، نه وعدهٔ خروجی یکسان برای همهٔ متن‌ها.

### نوشتن از روی داده‌های خودتان

```text
/human-speak از این نکته‌ها یک پست لینکدین رسمی و ساده بنویس؛ ادعای تازه اضافه نکن:
[نکته‌ها]
```
